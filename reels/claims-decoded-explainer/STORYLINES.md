# Fire Claims Decoded: explainer video, three storylines

What the film explains, in one line: **Fire Claims Decoded** is a series by an
engineer in property insurance that takes one occupancy at a time, shows how
fires start there and gives a few practical ways to prevent them, so you never
need to make the claim.

The one thing to remember: *fire causes are all around us, and most people
never notice them.*

Sources: `.claude/instagram/voice.md` and the restaurant kitchen fires reel.
Every line and number on screen comes from those. Nothing is invented.

Assumptions for all three: vertical 1080x1920, 25 to 35 s, motion graphics only
(no presenter footage), "Fire Claims Decoded" as a header, every label short and
spelled correctly, ends on Like / Follow / Comment with @parag_pethe1.

---

## A. Smaller than your thumb (recommended)

**Device and form:** the object is the explanation, as an endless zoom.

The viewer sees an ordinary shop wall and zooms into a single socket until a
loose connection fills the screen and sparks. The zoom carries on into one
hidden cause after another, each a different building, then pulls all the way
out to show they were in one street the whole time.

- **First 2 s:** a wall socket on a shop wall, already on screen at frame 0,
  with the line "Most fire claims start with something smaller than your
  thumb." The camera starts pushing in.
- **Beats:** socket → spark on a loose connection ("Loose wiring") → the zoom
  lands in a restaurant hood ("Grease in the duct") → a warehouse aisle ("Blocked
  aisles") → a cracker shop ("Overstocking") → pull out to the whole street:
  "We are surrounded by fire causes" → "Fire Claims Decoded: one occupancy at a
  time" → Like / Follow / Comment.
- **Look:** flat engineering-drawing style, off-white ground with dark line
  work; fire orange as the only accent, used only on the cause in each scene.
  Bold condensed sans-serif labels.
- **Sound:** a low, steady pulse that tightens on each zoom; a short crackle on
  each spark; it opens up on the pull-out.

## B. Decoded

**Device and form:** type carries the argument, cut on the beat.

A stamped claim file fills the screen. The cause on it is a scrambled line
that resolves, letter by letter, into plain words; then the fix types out
beneath it. Three files, three occupancies, faster each time.

- **First 2 s:** a red "FIRE CLAIM" stamp hits an empty file card. Under it,
  "Cause:" followed by scrambled letters already shuffling.
- **Beats:** file 1: Restaurant kitchen → "Grease in the duct" → "Filters every
  7 days" / "Ducts every 3 months" → file 2: Warehouse → "Blocked aisles" →
  "Caged, segregated storage" → file 3: Cracker shop → "Overstocking" → "Stock
  within limits" → the files stack up: "Every claim had a cause you could see"
  → series name → Like / Follow / Comment.
- **Look:** manila file card on a charcoal desk, typewriter-style monospace for
  the file, a heavy sans for the decoded words; stamp red as the accent.
- **Sound:** a dry, ticking beat; a stamp thud on each file; soft key ticks as
  the letters resolve.

## C. One street, one take (the bold one)

**Device and form:** a flight through one world in one continuous take.

The camera glides sideways along a single Indian street: a home, a shop, a
restaurant, a warehouse, a factory. In each, one hazard glows faintly. As the
camera passes, the fix clicks into place and the glow goes out. It never cuts.

- **First 2 s:** a street of building fronts at dusk, already moving; a home's
  window shows a glowing overloaded socket, labelled "Loose wiring".
- **Beats:** home: "Loose wiring" → "Annual electrical audit" → restaurant:
  "Greasy duct" → "Clean filters" → warehouse: "Blocked aisles" → "Clear the
  path" → cracker shop: "Overstocking" → "Valid licence" → the camera rises
  over the whole street, every glow out: "Awareness is the first step" →
  series name → Like / Follow / Comment.
- **Look:** flat illustrated building fronts in warm dusk colours, one hazard
  glow per building in orange, clean white labels.
- **Sound:** a calm, warm bed at walking pace; a soft click each time a fix
  lands; the music lifts as the camera rises.
